# STM32 Parametric Explorer



View STM32 MCUs and CPUs in a 3D/4D graph. 

It might bring some useful insights comparing e.g. different Arm core generations that might be not exactly easy to dig out on the st website.

This project is quick and dirty best effort with absolutely no guarantees for correctness but is trying to compensate by trying to look cool.

Everything with the exception of this readme is 100% pure claude vibe coded and is guaranteed to have never been viewed by a human.



Prices are Mouser 1K qty.

The Attributes section is just a quick pick at some attributes that sounded interesting. It is by no means an exhaustive list.
